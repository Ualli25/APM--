# Примеры промптов для учебных лабораторных

Эти промпты показывают, как можно использовать ИИ-чат в Cursor или VS Code с Copilot Chat. Код, предложенный ИИ, нужно проверять и запускать, а не принимать вслепую.

## Лабораторная 1 — проектирование и структура

> Я разрабатываю информационную систему «АРМ секретаря Учёного совета». По исходной схеме базы опиши сущности, первичные и внешние ключи, связи между сущностями и предложи модульную структуру проекта на FastAPI, SQLModel и Streamlit. Не удаляй существующий Flask-вариант и не включай локальные базы SQLite в Git.

## Лабораторная 2 — ORM и база данных

> Проверь SQLModel-модели проекта «АРМ секретаря Учёного совета». Для каждой связи укажи, где хранится внешний ключ и где используется Relationship. Проверь, что скрипт инициализации создаёт SQLite-базу, а seed-данные добавляются только в пустую базу и связаны корректными идентификаторами.

## Лабораторная 3 — REST API

> Проверь маршруты FastAPI для членов совета, соискателей, диссертаций и заседаний. Создай примеры GET и POST запросов, проверь валидацию входных данных и использование Depends(get_session). Для ошибок возвращай понятные HTTP-коды.

## Лабораторная 4 — интерфейс

> Проверь Streamlit-интерфейс АРМ секретаря. Он должен получать данные через REST API, показывать ошибку при недоступности backend и позволять создать члена совета, соискателя, дело и заседание.

## Лабораторная 5 — интеграция и бизнес-правила

> Проведи ревью проверки кворума и оформления протокола: требуется не менее двух третей состава совета и минимум три профильных доктора наук; протокол нельзя оформить без кворума; результат решения должен сохраняться вместе с голосами и менять статус дела.

## Лабораторная 6 — Docker

> Проверь Dockerfile backend, Dockerfile.frontend и docker-compose.yml. Backend должен быть доступен Streamlit по имени сервиса backend:8000, SQLite должна переживать пересоздание контейнера через именованный том, а локальные базы, .venv и секреты не должны попадать в Docker build context.

## Лабораторная 7 — тестирование и безопасность

> Проанализируй тесты FastAPI. Добавь интеграционные проверки для GET списка, POST с корректными и ошибочными данными и сценария кворума. Тесты должны использовать изолированную SQLite-базу и не менять рабочие данные проекта.
